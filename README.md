# ParkView — frontend

Клиентская часть приложения для поиска парковок. Интерфейс позволяет просматривать парковки на карте, искать адреса, проверять доступность мест, открывать схему парковки и сохранять парковки в избранное.

## Требования

- Node.js 20.19+ или 22.12+
- npm

## Запуск локально

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале (обычно `http://localhost:5173`).

## Команды

```bash
npm run dev      # запуск сервера разработки
npm run build    # проверка TypeScript и production-сборка
npm run lint     # проверка Oxlint
npm run preview  # просмотр production-сборки локально
```

## Текущие ограничения

- Данные парковок демонстрационные и сейчас относятся к Москве.
- Пользователи, аккаунты и избранное хранятся в `localStorage` браузера. Это прототипная реализация, не предназначенная для хранения реальных паролей или персональных данных.
- Карта использует тайлы OpenStreetMap, а поиск адресов — сервис Nominatim. Для их работы требуется подключение к интернету; соблюдайте правила использования этих сервисов.
